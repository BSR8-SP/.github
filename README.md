<h1 align="center">BSR8-SP</h1>
<h3 align="center">Avaliação das linhas de ônibus de São Paulo</h3>

<p align="center">
Esta organização foi criada com o objetivo de gerenciar o desenvolvimento de um site focado na avaliação das linhas de ônibus de São Paulo.
</p>

<p align="center">
Ao todo, o projeto reúne diferentes partes do sistema, incluindo aplicação WEB e um servidor, organizados em repositórios separados.
</p>
